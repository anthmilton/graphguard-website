## ONE-TIME VERCEL SETUP (Anth Does This Once)

**Takes 2 minutes, then Skippy owns it forever.**

### Step 1: Import to Vercel

1. Go to https://vercel.com/dashboard
2. Click "Add New..." → "Project"
3. Click "Import" next to `anthmilton/graphguard-website`
4. Configure:
   - **Framework Preset:** Hugo (should auto-detect)
   - **Root Directory:** `./` (default)
   - **Build Command:** `hugo --minify` (should auto-fill)
   - **Output Directory:** `public` (should auto-fill)
5. Click "Deploy"

### Step 2: Connect Custom Domain

1. Once deployed, go to Project Settings → Domains
2. Add domain: `graphguard.ca`
3. Vercel will give you DNS records
4. Add those DNS records to GoDaddy (where graphguard.ca is registered):
   - **Type:** A
   - **Name:** `@`
   - **Value:** `76.76.21.21` (Vercel's IP)
   - **Type:** CNAME
   - **Name:** `www`
   - **Value:** `cname.vercel-dns.com`
5. Wait 5-10 minutes for DNS to propagate
6. Site will be live at https://graphguard.ca
